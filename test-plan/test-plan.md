# Plan testów

## Wprowadzenie

**Aplikacja:** AcademyBugs
**Rodzaj testów:** Testy manualne

## Cel testów

- Identyfikacja błędów.
- Trenowanie pisania przejrzystych przypadków testowych.
- Weryfikacja wymagań funkcjonalnych.

## W zakresie testów

- Lista produktów.
- Szczegóły produktów.
- Funkcjonalność koszyka.
- Nawigacja.
- Interfejs.

### Poza zakresem testóe

- Testy wydajnościowe i obciążeniowe.
- Testy bezpieczeństwa i testy penetracyjne.
- Testy automatyczne.

## 4. Podejście do testowania

Testy będą przeprowadzane manualnie przy użyciu przeglądarki internetowej.

Proces ten będzie obejmował:
1. Przegląd wybranej funkcji i jej oczekiwanego zachowania.
2. Przygotowanie przypadków testowych.
3. Przeprowadzenie testów.
4. Rejestrowanie rzeczywistych wyników.
5. Zgłaszanie powtarzalnych błędów.
6. Wykonanie zrzutów ekranu lub zebranie innych dowodów, jeśli jest to przydatne.

## 5. Środowisko testowe

- **Strona internetowa:** https://academybugs.com/find-bugs/
- **Metoda testowania:** Ręczna
- **Przeglądarka:** Microsoft Edge
